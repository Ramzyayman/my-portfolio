# Ramzy Ayman — Personal Developer Portfolio

Clean, minimalist, and developer-centric personal portfolio website for **Ramzy Ayman**, Software Engineering Student (Class of 2027) based in Cairo, Egypt.

## Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Linter**: [Oxlint](https://oxc.rs/)

## Features

- **Refined Dark Mode & High Contrast**: Built with a sleek dark palette by default and an instant light mode toggle.
- **Featured Systems & Architecture Specs**: In-depth breakdowns and architecture modals for projects including Ramscraft, Ricksy Store, Papyr, Kaszinó, Hall of Shame, Contacts API, and PaletteApp.
- **Categorized Skills Matrix**: Practical breakdown across Languages, Full-Stack & Backend, Databases & State, and DevOps & Tooling.
- **Single Source of Truth**: All data and content centralized in `src/data/portfolioData.ts`.
- **Keyboard Shortcuts**: Quick hotkeys (`P` for projects, `S` for skills, `C` for contact, `T` for theme).

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Type check and build production bundle
npm run build

# Run linter
npm run lint
```
